🧩 Why Do We Need Padding?

A 3×3 filter needs 3 rows and 3 columns to work. But at the edges of a 5×5 image, the filter would stick out! So we add a 1-pixel border all around, making it 7×7. Now the filter can slide over every original pixel.

Formula: For a filter of size F×F, padding = (F-1)/2 on each side. For 3×3 filter: pad = (3-1)/2 = 1 pixel. So 5×5 + 1 pixel pad = 7×7. The filter now centers on every original pixel!
